# 🐍 NEON SNAKE - Неоновая Змейка

Классическая игра "Змейка" в неоновом киберпанк стиле с таблицей рекордов!

## Запуск:
  `npm install`
  `npm run dev`

## ✨ Особенности

### 🎮 Геймплей
- **Классическая механика** - управляйте змейкой и собирайте яблоки
- **Прогрессивная сложность** - скорость увеличивается с каждым съеденным яблоком
- **Неоновая графика** - стильный киберпанк дизайн с светящимися эффектами
- **Плавная анимация** - все движения и эффекты анимированы

### 🎯 Возможности
- 🏆 **Таблица рекордов** - сохраняет топ-10 лучших результатов
- 💾 **Локальное хранение** - рекорды сохраняются в браузере
- 📱 **Мобильное управление** - сенсорные кнопки для смартфонов
- ⏸️ **Пауза** - остановка игры в любой момент
- 🔄 **Быстрый рестарт** - начать новую игру одной кнопкой
- 🔊 **Звуковые эффекты** - 8-битные звуки (можно отключить)
- 🌀 **Два режима игры**:
  - 🧱 Режим стен - столкновение со стеной = game over
  - 🌀 Режим телепорта - проход через стены на другую сторону
- ✨ **Эффекты частиц** - красивая анимация при поедании яблока

### 🎨 Визуальные эффекты
- Неоновое свечение всех элементов
- Анимированная сетка игрового поля
- Градиентные цвета (cyan, purple, pink)
- Пульсирующие анимации
- Эффект размытия при Game Over

### 📊 Статистика
- **Счёт** - количество очков (10 за каждое яблоко)
- **Рекорд** - ваш лучший результат
- **Длина** - текущая длина змейки
- **Скорость** - текущий множитель скорости

## 🎮 Управление

### ⌨️ Клавиатура
- **Стрелки** (↑ ↓ ← →) - управление направлением
- **WASD** - альтернативное управление
- **Пробел** - пауза/продолжить
- **Enter** - новая игра (после Game Over)

### 📱 Мобильные устройства
- Используйте сенсорные кнопки-стрелки на экране
- Кнопки расположены в нижней части экрана

## 🏆 Таблица рекордов

- Автоматически сохраняет топ-10 результатов
- Показывает имя игрока, счёт и дату
- Медали для первых трёх мест:
  - 🥇 1 место - золото
  - 🥈 2 место - серебро
  - 🥉 3 место - бронза
- Данные хранятся в localStorage браузера

## 🎯 Правила игры

1. **Цель** - собирать яблоки и набирать очки
2. **Движение** - змейка постоянно движется вперёд
3. **Рост** - каждое съеденное яблоко увеличивает длину на 1 сегмент
4. **Ускорение** - скорость игры увеличивается с каждым яблоком
5. **Проигрыш** - игра заканчивается при:
   - Столкновении со стеной
   - Столкновении с собственным телом

## 🛠️ Технологии

- **React 18** - UI фреймворк
- **JavaScript (JSX)** - язык программирования
- **Tailwind CSS** - стилизация и анимации
- **Vite** - сборщик проекта
- **LocalStorage API** - хранение рекордов
- **Web Audio API** - звуковые эффекты

## 💡 Технические детали

### Настройки игры (константы)
```javascript
GRID_SIZE = 20        // Размер игрового поля (20x20)
CELL_SIZE = 25        // Размер одной клетки в пикселях
INITIAL_SPEED = 150   // Начальная скорость (мс между тиками)
SPEED_INCREMENT = 5   // Ускорение за каждое яблоко
```

### Архитектура
- **Функциональные компоненты** с хуками
- **useState** - управление состоянием
- **useEffect** - игровой цикл и события
- **useCallback** - оптимизация производительности
- **useRef** - управление интервалами
- **Custom Hook (useSound)** - генерация звуков через Web Audio API

### Компоненты
- `App` - основной компонент игры
- `GameBoard` - игровое поле
- `Leaderboard` - таблица рекордов
- `Settings` - панель настроек
- `Particle` - эффекты частиц

## 🎮 Советы для игры

1. **Планируйте маршрут** - не загоняйте себя в угол
2. **Используйте центр** - старайтесь держаться ближе к центру поля
3. **Не спешите** - на высоких скоростях будьте осторожнее
4. **Используйте паузу** - остановитесь, чтобы продумать следующий ход
5. **Практика** - чем больше играете, тем лучше результат!
